# Installation du serveur Wazuh

## VM
- Nom : Ubuntu-soc-lab
- OS : Ubuntu Server 22.04
- RAM : 2-2,5 Go, 2 CPU
- Réseau : VMnet2 (lab) + NAT (ajoutée après install, pour accès Internet)

## Étapes
1. Installation d'Ubuntu Server depuis l'ISO officielle
2. Ajout d'une 2ᵉ carte réseau NAT après l'installation (nécessaire pour télécharger Wazuh)
